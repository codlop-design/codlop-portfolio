# بورتفوليو كود لوب

المشروع صفحة ثابتة: HTML وCSS وJavaScript مع الصور والخطوط والأيقونات في مجلد `assets`.

## التشغيل محليًا

من داخل المجلد بعد فك الضغط:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. يمكن رفع محتويات المجلد كما هي إلى استضافة ملفات ثابتة.

## ملاحظات

- نموذج التواصل يجهز رسالة واتساب، والزائر يرسلها بنفسه.
- نافذة مساعد كود لوب تستخدم ردودًا محلية للأسئلة الشائعة، ولا تتصل بخدمة ذكاء اصطناعي.
- صور المشاريع وشعارات العملاء مأخوذة من الأعمال المعروضة في موقع كود لوب.
